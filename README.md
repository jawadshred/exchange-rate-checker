# Exchange Rate Checker

A simple client-side GitHub Pages page to compare a shop's exchange rate against the Google exchange rate.

## Usage

1. Open `index.html` in a browser.
2. Enter the Google rate.
3. Enter the shop rate.
4. Click **Calculate percentage difference**.
5. The result is shown in red/yellow/green based on the difference.

## GitHub Pages setup

1. Create a GitHub repository and push this folder to the repository.
2. In the repository settings, open **Pages**.
3. Choose the branch `main` (or `master`) and root folder `/`.
4. Save.
5. After a few minutes, your page will be available at `https://<your-username>.github.io/<repo-name>/`.

If this is a user site repository named `<username>.github.io`, the page will appear at `https://<username>.github.io/`.
